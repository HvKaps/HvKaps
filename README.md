### 👨‍💻 À propos : Dev x Design

Mon objectif est de supprimer la friction classique entre design et développement :

- 🎨 **Côté UI/UX :** Prototypage sous **Figma** avec des Design Systems pensés dès le départ pour l'intégration (composants modulaires, contraintes CSS respectées, accessibilité RGAA).
- 💻 **Côté Code :** Intégration front-end réactive (**React, TypeScript, Tailwind CSS**) reliée à des architectures back-end solides (**Java Spring Boot, MySQL, Docker**).
- 🛠️ **Expérience terrain :** Missions en agence chez **Adstriver** et **SeedBox** : refontes sous délais serrés, administration de serveurs Linux en prod et reverse proxy Nginx.
